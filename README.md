# 室町時代クイズ（小5・7月）

中学受験サポート用のクイズアプリです。小5・7月の演習から、全20問を出題します。

## 出題内容
- 室町幕府のしくみ（管領・侍所・鎌倉府）
- 足利尊氏・義満・義政
- 建武の新政と後醍醐天皇、南朝と北朝（吉野・南北朝合一）
- 応仁の乱（細川勝元・山名持豊）と下剋上
- 16世紀の戦国大名（北条・武田・織田・毛利）
